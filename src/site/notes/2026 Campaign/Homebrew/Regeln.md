# Allgemein
- DM cheatet nicht, um Spieler zu "retten"
- Charaktere können Sterben
	- neuer Char für nächste Session
- Gegner könnten nicht durch Kampf bezwingbar sein
- es gibt Crits bei allen Würfen
- Rule of Cool
- DM entscheidet Regel Auslegung

## 100 Fragen
- Bei jeder Long Rest wird ein D100 gewürfelt
- Die Helden lernen sich besser kennen
- Antwort muss nicht 100% wahr beantwortet werden, sondern so wie der Chat es den anderen Helden sagen würde

# Charaktere
## Charakter Erstellung
- Werte werden gerollt in Session 0
	- Kein Point Buy erlaubt
	- Kein Standard Array erlaubt
	- Bei Absolutem Dog-Shit ist ein kompletter Reroll möglich
		- DM Entscheidung
## Erlaubte Klassen
- Standard Klassen
	- Barbarian
	- Bard
	- Cleric
	- Druid
	- Fighter
	- Monk
	- Paladin
	- Ranger
	- Rogue
	- Sorcerer
	- Warlock
	- Wizard
- Weitere Klassen
	- Monster Hunter
	- Pugilist
	- Illriger
	- Blood Hunter
## Erlaubte Rassen
- Keine Rasse mit Fly Speed
## Erlaubte Items
- Als Start Items nur Adventuring Gear
- Keine Schusswaffen

# Kampf
## Crits
- bei kritischen Erfolgen und Fehlschlägen wird auf eine 100er Tabelle gewürfelt
## Charakter Down (0 HP)
- Death Saving Throws werden beim DM gewürfelt
- 1 Level Exhaustion
	- Minus 3 Level Exhaustion bei jeder Long Rest
	- Optional: Minus 1 Level Exhaustion statt Heilung bei Short Rest
## Charakter Tod
- Charakter Tod ist jederzeit möglich
- Werte für den neuen Charakter werden am Ende der Session gerollt
	- Minus 1 auf einen Wert (stackt mit jedem Tod)
		- soll vermeiden den Charakter absichtlich zu killen, um bessere Werte zu bekommen
- Neuer Charakter ist **neu**
	- Andere Klasse
	- Andere Rasse
### Heroic Turn
- Direkt nach Charakter Tod
- Sofort alle Spell Slots, Class Features und Uses von Magic Items zurück
- eine finale Runde für ein heldenhaftes abtreten
